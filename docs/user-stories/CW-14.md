# CW-14: Keyboard-reachable, easily selectable UI elements

## User Story

As a user with a motor impairment, I want interactive elements to be clearly identifiable, reachable by keyboard, and large enough to select reliably so that I can operate the app without precise pointing.

## Acceptance Criteria

- [ ] **Given** I navigate the application using only the keyboard **When** I move focus through the page **Then** every control is reachable in a logical order and shows a visible focus indicator
- [ ] **And when** I hover or focus a control **Then** it is visually distinguishable from non-interactive content.
