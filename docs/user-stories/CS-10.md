# CS-10: Store and expose sensor error history

## User Story

As a system operator, I want the server to store sensor error events and expose them by time so that I can review a sensor’s failure history.

## Acceptance Criteria

- [ ] **Given** a sensor reports an error event with a code, message, and timestamp **When** the errors for that sensor are requested for a time range **Then** the matching events are returned in timestamp order.
