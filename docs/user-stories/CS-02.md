# CS-02: Authenticate sensors via key/certificate

## User Story

As a system operator, I want sensors to authenticate with a unique key or certificate so that only authorized sensors can write scan data.

## Acceptance Criteria

- [ ] **Given** a sensor submits scan or status data **When** the server validates its credential **Then** the data is accepted
- [ ] **And given** the credential is missing, unknown, or revoked **Then** the request is rejected with an authentication error and the attempt is logged.
