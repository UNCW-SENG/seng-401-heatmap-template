# SN-09: Include MAC, RSSI, timestamp in each scan

## User Story

As a system operator, I want each detected scan to include MAC address, RSSI, and timestamp so that the server can estimate device positions.

## Acceptance Criteria

- [ ] **Given** a Wi-Fi device is detected **When** the scan data is sent **Then** MAC, RSSI, and timestamp are included, along with the sensor’s unique ID.
