# SN-08: Never log credentials

## User Story

As a system operator, I want credentials to never appear in log files or console output so that logs can be shared for debugging without leaking secrets.

## Acceptance Criteria

- [ ] **Given** the sensor has been running and has logged startup, transmission, and error events **When** I inspect the log file and the console output **Then** no API key, password, token, or certificate private key appears in any entry.
