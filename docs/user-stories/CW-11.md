# CW-11: Distinct empty state when no devices detected

## User Story

As a user, I want a distinct empty state when no devices are detected so that I can tell “nobody is there” from “it is broken.”

## Acceptance Criteria

- [ ] **Given** the server responds successfully with no device positions **When** the heatmap renders **Then** the interface states that no devices were detected, and this state is visually distinct from the loading state and from an error state.
