# CS-13: Filter stationary devices from density calc

## User Story

As a system operator, I want stationary devices (printers, access points, desktop computers) filtered out of the density calculation so that the heatmap reflects people rather than equipment.

## Acceptance Criteria

- [ ] **Given** a MAC address is observed at essentially the same estimated position across a configured number of consecutive time windows **When** positions are computed **Then** that device is classified as static and excluded from the reported density.
