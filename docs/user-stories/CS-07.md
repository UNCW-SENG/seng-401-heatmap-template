# CS-07: Store and retrieve floorplan and sensor coordinates

## User Story

As a client application developer, I want to store and retrieve a space’s floorplan and the physical coordinates of each sensor in it so that the client can render the map correctly.

## Acceptance Criteria

- [ ] **Given** a floorplan image and a set of sensor coordinates are submitted for a space **When** the client requests that space **Then** the server returns the floorplan and the position of every sensor assigned to it.
