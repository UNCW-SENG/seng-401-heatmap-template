# SN-05: Send periodic heartbeats

## User Story

As a system operator, I want the sensor to send periodic “still online” heartbeats so that the server can tell a quiet sensor from a dead one.

## Acceptance Criteria

- [ ] **Given** the scanner is running and no scans have been detected **When** the configured heartbeat interval elapses **Then** a heartbeat message containing the sensor ID and a timestamp is sent to the server.
