# CS-14: Log every request with correlation ID

## User Story

As a developer, I want every request logged with a correlation ID, the identity of the caller, and the outcome so that I can trace an incorrect heatmap back to the scan data that produced it.

## Acceptance Criteria

- [ ] **Given** any request is received **When** it is processed **Then** a log entry records a correlation ID, the sensor or user identity, the operation, and the result, and the same correlation ID appears in every downstream log entry for that request.
