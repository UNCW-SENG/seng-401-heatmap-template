# SN-06: Authenticate sensor to server

## User Story

As a system operator, I want the sensor to authenticate itself to the server so that only approved sensors can submit scan data.

## Acceptance Criteria

- [ ] **Given** a valid credential (API key or certificate) is present in the configuration **When** the sensor transmits data **Then** the server accepts the transmission
- [ ] **And given** an invalid or missing credential **When** the sensor transmits data **Then** the transmission is rejected and the failure is written to the local log.
