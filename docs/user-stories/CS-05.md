# CS-05: Validate and reject malformed scan records

## User Story

As a system operator, I want the server to validate incoming scan records and reject malformed data so that bad data never reaches the database.

## Acceptance Criteria

- [ ] **Given** a submitted record contains a malformed MAC address, an out-of-range RSSI, an unknown sensor ID, or a timestamp far in the future or past **When** the record is processed **Then** it is rejected with a descriptive error, the rejection is logged, and no partial record is written.
