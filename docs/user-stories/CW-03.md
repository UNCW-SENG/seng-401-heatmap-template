# CW-03: Show clear message on auth failure

## User Story

As a user, I want a clear message when authentication fails so that I know whether to retry or ask for help.

## Acceptance Criteria

- [ ] **Given** I submit credentials that are rejected **When** the response is received **Then** the interface shows a specific, readable message explaining that sign-in failed and what to do next, without revealing whether the account exists.
