# CW-10: Show last-updated time and stale-data warning

## User Story

As a user, I want the display to show when the data was last updated and warn me when it has gone stale so that I never mistake a frozen map for an empty room.

## Acceptance Criteria

- [ ] **Given** the heatmap is displayed **When** a refresh succeeds **Then** the interface shows how recently the data was updated
- [ ] **And when** refreshes stop succeeding past a defined threshold **Then** a visible warning indicates the data is stale and the display is no longer live.
