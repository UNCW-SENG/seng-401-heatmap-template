# CS-06: Idempotent scan batch submissions

## User Story

As a system operator, I want repeated submissions of the same scan batch to be idempotent so that a sensor’s retry after a timeout does not double-count devices.

## Acceptance Criteria

- [ ] **Given** a batch of scan records identified by a batch ID has already been stored **When** the same batch is submitted again **Then** the server acknowledges it successfully and stores no duplicate records.
