# CW-05: Calibrate floorplan to real-world units

## User Story

As a system operator, I want to calibrate the floorplan to real-world units so that positions and distances shown on the map are physically meaningful.

## Acceptance Criteria

- [ ] **Given** a floorplan image is loaded **When** I mark two points and enter the real distance between them **Then** the app stores the scale and renders sensor and device positions at their correct physical locations.
