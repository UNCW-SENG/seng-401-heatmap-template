# CW-02: Sign up, log in, and log out

## User Story

As a user, I want to sign up, log in, and log out so that my access to the system is controlled.

## Acceptance Criteria

- [ ] **Given** I am on the sign-up page **When** I submit an email and password **Then** an account is created through the server API and I can log in with it
- [ ] **And given** I am logged in **When** I select log out **Then** my session is ended and I am returned to the login page.
