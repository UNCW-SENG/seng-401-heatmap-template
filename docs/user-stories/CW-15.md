# CW-15: Cross-browser and tablet-responsive interface

## User Story

As a user, I want the interface to work on current versions of Chrome, Firefox, and Safari and on a tablet-sized viewport so that I can check the space from whatever device I have.

## Acceptance Criteria

- [ ] **Given** I open the application in a current version of Chrome, Firefox, or Safari **When** the heatmap page loads **Then** the map, sensors, heatmap, and controls render and function correctly
- [ ] **And when** the viewport is tablet-sized **Then** the layout adapts without clipping or horizontal scrolling.
