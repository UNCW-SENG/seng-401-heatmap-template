# SN-11: Rotate log files daily with retention window

## User Story

As a system operator, I want log files rotated daily with a configurable retention window so that logs do not fill the sensor’s storage.

## Acceptance Criteria

- [ ] **Given** a retention window of N days is configured **When** a new day begins **Then** a new log file is started and any log file older than N days is deleted.
