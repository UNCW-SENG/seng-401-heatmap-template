# CS-09: Auto-mark sensor offline/online by heartbeat

## User Story

As a system operator, I want a sensor marked offline after a defined number of missed heartbeats and returned to online on its next heartbeat so that status reflects reality without manual intervention.

## Acceptance Criteria

- [ ] **Given** a sensor’s last heartbeat is older than the configured threshold **When** its status is requested **Then** it is reported offline with the timestamp it was last seen
- [ ] **And when** a new heartbeat arrives **Then** its status returns to online.
