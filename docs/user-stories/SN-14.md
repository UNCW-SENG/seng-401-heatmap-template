# SN-14: Graceful shutdown on SIGTERM/SIGHUP

## User Story

As a system operator, I want the scanner to shut down gracefully on SIGTERM or SIGHUP so that a planned shutdown is not mistaken for a failure.

## Acceptance Criteria

- [ ] **Given** the scanner is running **When** the process receives SIGTERM or SIGHUP **Then** it stops capturing, flushes any cached records, writes a shutdown entry to the log, sends a “going offline” message to the server, and exits with a success status.
