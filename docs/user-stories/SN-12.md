# SN-12: Cache scan data offline and resend on reconnect

## User Story

As a system operator, I want the sensor to cache scan data locally when the server is unreachable and resend it on reconnect so that no data is lost during an outage.

## Acceptance Criteria

- [ ] **Given** the server cannot be reached **When** new scans are detected **Then** the records are written to a local cache of bounded size, discarding the oldest records when the cache is full
- [ ] **And when** connectivity is restored **Then** the cached records are transmitted and removed from the cache once acknowledged.
