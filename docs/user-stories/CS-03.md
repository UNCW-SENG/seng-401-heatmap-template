# CS-03: Register account and log in

## User Story

As a user, I want to register an account and log in with an email and password so that access to the system is controlled.

## Acceptance Criteria

- [ ] **Given** a new user submits an email and password **When** the account is created **Then** the password is stored salted and hashed and is never stored or returned in plaintext
- [ ] **And given** valid credentials are submitted at login **Then** the server issues a session credential the client can use on subsequent requests.
