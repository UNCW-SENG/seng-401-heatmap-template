# CW-01: Encrypt client-server communications (HTTPS)

## User Story

As a user, I want all communications between the client app and the cloud server to use HTTPS so that my data is secure.

## Acceptance Criteria

- [ ] **Given** the web app connects to the server **When** data is transmitted **Then** it uses HTTPS/TLS (verified by inspecting traffic).
