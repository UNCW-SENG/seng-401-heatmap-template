# SN-13: Detect and report fault conditions

## User Story

As a system operator, I want the sensor to detect and report fault conditions (Wi-Fi adapter removed, capture process died, low disk space) so that I can diagnose a sensor without physical access.

## Acceptance Criteria

- [ ] **Given** the scanner is running **When** a fault condition is detected **Then** a coded error event is written to the local log and sent to the server.
