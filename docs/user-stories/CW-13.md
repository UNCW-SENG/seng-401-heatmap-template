# CW-13: Enlarge text and select accessible color palette

## User Story

As a user with low vision, I want to enlarge the text and select a high-contrast or color-blind-safe heatmap palette so that I can read the display.

## Acceptance Criteria

- [ ] **Given** I am on the settings page **When** I enable enlarged text or select an alternate palette **Then** the setting applies across the application, persists for my account, and the heatmap remains interpretable without relying on red–green discrimination.
